FreezeFrame interface prototypes

Five directions for the live demo. Each one plays the same recorded replay (the real 8-payment cycle and the real results), so only the design changes. Open one and press Play.

01

Lanes

Operations console

One row per bank, time running left to right. You see the money step between banks as it happens.

Best for
A live operator view, and judges asking "how does it run?"
Theme
Dark graphite · IBM Plex
02

Ring

Editorial

The cycle is drawn as a ring, so the money visibly comes back to where it started.

Best for
Screenshots, the deck, and a first impression
Theme
Light paper · Fraunces
03

Split

Alone vs together

The comparison is the layout. Each hop reads across from "a bank alone" to "together in the enclave".

Best for
Making the privacy-dividend argument in one glance
Theme
Dark ink · Bricolage Grotesque
04

Boundary

The enclave, drawn

Banks sit on one side and the enclave in the middle. Each bank sees only its own fragment; only the enclave sees the whole chain.

Best for
Explaining why no customer data is shared
Theme
Blueprint navy · Red Hat
05

Story

Presenter mode

One hop at a time, in large type for a projector, and it ends on the results slide. Keyboard: Space, R, ← →.

Best for
The 3-minute pitch
Theme
Near-black stage · Newsreader
06 · combined

Story × Split

Story's look, Split's structure

Each hop reads across from "a bank alone" to "together in the enclave", on Story's near-black stage. Skipped hours appear as dividers between the hops they separate.

Best for
The live demo and the pitch, in one page
Theme
Near-black stage · Newsreader + Geist

Data: data.js holds the demo chain, the results in results/HI-Small/, and a recorded replay from the live demo. sim.js plays it back at the server's real cadence. When you pick one, it gets wired to the live server (/api/stream) in demo/static/index.html.
